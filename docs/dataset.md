## Column Meaning

- **Dataset**：数据集名称  
- **Task**：Excel 原始任务字段（人工整理）  
- **Img pairs**：成对图像数量（未知为 —）  
- **Resolution**：典型分辨率（未知为 Various）  
- **Color**：是否包含 RGB（✅=是，❓=不确定）  
- **Obj/Cats**：目标数 / 类别数  
- **Cha-Sc**：是否包含挑战场景  
- **Anno**：是否提供标注  
- **DownLoad**：数据集主页或论文链接
